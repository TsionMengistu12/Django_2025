### Todo CLI

Simple command-line todo manager with JSON persistence.

#### Features

- Add, view, update, and delete tasks
- Marks tasks completed/incomplete
- Stores data in `todos.json` in the project root

#### Run

```bash
python -u "c:\\Django_2025\\miniproject\\main.py"
```
